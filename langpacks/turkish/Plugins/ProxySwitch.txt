[Any entry in the 'Use proxy' list can be prefixed by an exclamation mark (!) to increase its priority. Entries with wrong syntax will be ignored. The plugin checks the IP addresses in the following way:]
“Proxy kullan” listesindeki herhangi bir girdinin önüne bir ünlem işareti (!) eklenerek önceliği artırılabilir. Sözdizimi hatalı girdiler göz ardı edilir. Eklenti, IP adreslerini şu şekilde kontrol eder:
[\t1) Use proxy if any interface has prioritized 'Use proxy' address\n\t2) Don't use proxy if any interface has 'Direct connection' address\n\t3) Use proxy if any interface has 'Use proxy' address\n\t4) Do nothing if unknown or no address found]
\t1) Herhangi bir arayüzde “Proxy kullan” adresi öncelikli olarak ayarlanmışsa proxy kullan\n\t2) Herhangi bir arayüzde “Doğrudan bağlantı” adresi varsa proxy kullanma\n\t3) Herhangi bir arayüzde “Proxy kullan” adresi varsa proxy kullan\n\t4) Bilinmiyorsa veya adres bulunamıyorsa hiçbir işlem yapma
