[String replacing variables...\r\nThe following are all the valid variables that can be used. Refer to the wiki.miranda-ng.org for a proper explanation.\r\n\r\nfile(X)\t\t<- specifies the file to read from. MUST be followed by either start() or end() or wholeline()\r\nfilename(X)\t<- copies the filename of file X.\r\nstart(...)\t\t<- specifies where to start copying from.\r\nend(...)\t\t<- specifies where to stop copying.\r\nwholeline(line(...))\t<- specifies a whole line to copy\r\n\r\nstart() and end() explained\r\n.........................\r\nMUST start with line() followed by a number or a string inside " marks, OR csv(separatorX) variable. The number specifies which character in the line to start/end copying. The string specifies a string in the line to start/end copying.\r\n\r\ncsv(seperatorX) explained...\r\nSeperator is either "tab" or "space" or any SINGLE character. X is the Xth separator to pass before copying, (or to stop before).\r\n\r\nLastly the line(...) variable...\r\nInside the brackets must be either a number (to specify the line number), or a string inside " marks (to use the line with that string), or lastline(X). The X in lastline is the Xth line above the last line, i.e., lastline(1) will use the 2nd last line of the file. If searching for a line with "some words" you may put a + or - X after the closing ), i.e., line("some words")+3 to go 3 lines after the line with "some words".\r\n\r\nSome examples...\r\nfilename(0)    <- will display the filename of the 0th file\r\nfile(0)wholeline(line(0)))    <- will display the whole first line of the 0th file\r\nfile(0)wholeline(line("hello")-1)))    <- the wholeline above the first occurrence of "hello" in the file\r\nfile(0)start(line(lastline(1))csv(tab2))end(line(lastline())csv(tab4)))    <- starts at the 2nd last line of the file, from the 2nd tab variable, until the 4th tab variable in the last line (in the 0th file)\r\nfile(0)start(line("hello")+1"zzzz")end(line(6)17))    <- starts from the first occurrence of zzzz in the line after the first occurrence of hello, until the 17th character in the 6th line (starting from line 0) of the 0th file.\r\n]
Dizgide değişkenlerin değiştirilmesi...\r\nAşağıda, kullanılabilecek tüm geçerli değişkenler listelenmiştir. Ayrıntılı açıklama için wiki.miranda-ng.org adresine bakınız.\r\n\r\nfile(X)\t\t<- okunacak dosyayı belirtir. Ardından mutlaka start(), end() veya wholeline() gelmelidir.\r\nfilename(X)\t<- X dosyasının dosya adını kopyalar.\r\nstart(...)\t\t<- kopyalamaya nereden başlanacağını belirtir.\r\nend(...)\t\t<- kopyalamanın nerede biteceğini belirtir.\r\nwholeline(line(...))\t<- kopyalanacak bir satırın tamamını belirtir\r\n\r\nstart() ve end() açıklaması\r\n.........................\r\nline() ile başlamalı ve ardından " işaretleri içindeki bir sayı veya dize, YA DA csv(separatorX) değişkeni gelmelidir. Sayı, satırda kopyalamaya başlanacak/biterecek karakteri belirtir. Dize, satırda kopyalamaya başlanacak veya son verilecek bir dizeyi belirtir.\r\n\r\ncsv(seperatorX) açıklaması...\r\nAyırıcı, "sekme", "boşluk" veya herhangi bir TEK karakter olabilir. X, kopyalamaya başlamadan önce geçilmesi gereken (veya kopyalamayı durdurmak için önce gelmesi gereken) X'inci ayırıcıdır.\r\n\r\nSon olarak line(...) değişkeni...\r\nParantezlerin içinde ya bir sayı (satır numarasını belirtmek için), ya da " işaretleri içindeki bir dize (o dizeyi içeren satırı kullanmak için) ya da lastline(X) bulunmalıdır. lastline içindeki X, son satırın X numara yukarısındaki satırı ifade eder; yani, lastline(1) dosyanın sondan 2. satırını kullanır. "bazı kelimeler" içeren bir satırı arıyorsanız, kapanış parantezinin ()) arkasına + veya - X ekleyebilirsiniz; örneğin, "bazı kelimeler" içeren satırdan 3 satır sonrasına gitmek için line("bazı kelimeler")+3 yazabilirsiniz.\r\n\r\nBazı örnekler...\r\nfilename(0)    <- 0. dosyanın dosya adını görüntüler\r\nfile(0)wholeline(line(0)))    <- 0. dosyanın ilk satırının tamamını görüntüler\r\nfile(0)wholeline(line("hello")-1)))    <- dosyada "hello" ifadesinin ilk geçtiği satırın üzerindeki tüm satırı gösterir\r\nfile(0)start(line(lastline(1))csv(tab2))end(line(lastline())csv(tab4)))    <- dosyanın sondan 2. satırından başlar; 2. sekme değişkeninden, son satırdaki (0. dosyada) 4. sekme değişkenine kadar devam eder\r\nfile(0)start(line("hello")+1"zzzz")end(line(6)17))    <- 0. dosyada (0. satırdan başlayarak) 6. satırın 17. karakterine kadar, "hello" ifadesinin ilk geçtiği satırdan sonra "zzzz" ifadesinin ilk geçtiği yerden başlar.\r\n
